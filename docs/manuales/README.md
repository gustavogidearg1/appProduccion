# Manuales de App Producción

Versión 1.0 — Noviembre de 2026.

- Manual_Calidad_Comofra.pptx: hallazgos, respuesta, verificación de eficacia, anulación e indicadores (22 diapositivas).
- Manual_Mantenimiento_Comofra.pptx: órdenes correctivas, prueba y liberación, preventivos y calendario (30 diapositivas).

Incluyen capturas de capacitación e instrucciones por rol para Producción, responsables, gerencia y auditoría. Son material de uso interno y no sustituyen los procedimientos técnicos aprobados.

Los scripts para actualizar una instalación existente sin terminal están en ../hosting/calidad-mantenimiento/. Las migraciones y el SQL son alternativas: no aplicar ambos sobre los mismos campos.
